# F-Football

Mobile-first 3D football game project.

## Target
11v11 matches, Career Mode, smarter AI, touch controls and local Wi-Fi multiplayer.

## Build milestones
1. Playable 3D prototype
2. Passing, shooting, possession and match rules
3. Full 11v11 team AI
4. Career Mode
5. Local Wi-Fi multiplayer
6. Android optimization and release

The first prototype is browser-playable and intentionally lightweight.

## Current build
Milestone 2 is now implemented: possession, passing, shooting, goals, goalkeeper saves, tackles, match score, match timer and out-of-bounds resets.
